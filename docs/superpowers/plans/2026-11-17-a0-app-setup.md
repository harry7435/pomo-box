# A0 · 모노레포 전환과 앱 셋업 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 저장소를 npm workspaces 모노레포(`apps/web`, `apps/mobile`, `packages/core`)로 바꾸고, `@pomobox/core`를 공유하는 빈 Expo 앱을 dev/prod 변형과 EAS 프로필까지 갖춰 세운다.

**Architecture:** 루트 `package.json`이 workspaces를 선언하고 각 워크스페이스가 자기 `check` 스크립트를 가진다. `@pomobox/core`는 빌드 없이 TS 소스를 export하고, 경계 규칙(ESLint)과 그 검증 테스트를 소유한다. 웹(Vite)과 앱(Expo SDK 58, Expo Router `src/app`)은 `@pomobox/core`를 워크스페이스 의존성으로 가져온다. 앱의 `app.config.ts`는 `APP_VARIANT`로 이름·패키지 ID를 분기한다.

**Tech Stack:** npm workspaces, Expo SDK 58 (React Native 0.88, React 19.3.0, Expo Router), jest-expo, Vite 8, Vitest 5, ESLint 10, TypeScript 6

**Spec:** `docs/superpowers/specs/2026-11-17-a0-app-setup-design.md`

- [ ] **Step 5: 경계 테스트를 패키지 기준으로 옮기고 RN 케이스 추가 (실패 테스트)**

`packages/core/tests/core-boundary.test.ts`를 다음으로 교체한다. 기존 케이스의 경로 `src/core/...`는 `src/...`로, `src/App.tsx`(core 밖) 케이스는 `tests/sample.test.ts`(패키지 안이지만 src 밖)로 바뀐다. 기대값은 바꾸지 않는다.

```ts
// @vitest-environment node
import { fileURLToPath } from 'node:url'
import { ESLint } from 'eslint'
import { describe, expect, it } from 'vitest'

const BOUNDARY_RULES = new Set(['no-restricted-imports', 'no-restricted-globals', 'no-restricted-syntax'])
const packageRoot = fileURLToPath(new URL('..', import.meta.url))
const eslint = new ESLint({ cwd: packageRoot })

async function boundaryRuleIds(code: string, filePath: string): Promise<string[]> {
  const [result] = await eslint.lintText(code, { filePath })
  return result.messages
    .map((message) => message.ruleId)
    .filter((ruleId): ruleId is string => ruleId !== null && BOUNDARY_RULES.has(ruleId))
}

describe('@pomobox/core boundary', { timeout: 30_000 }, () => {
  it.each([
    ['react', "import 'react'\n"],
    ['react-dom/client', "import 'react-dom/client'\n"],
    ['dexie', "import 'dexie'\n"],
    ['firebase/firestore', "import 'firebase/firestore'\n"],
    ['@firebase/app', "import '@firebase/app'\n"],
    ['react-native', "import 'react-native'\n"],
    ['expo', "import 'expo'\n"],
    ['expo-sqlite', "import 'expo-sqlite'\n"],
    ['@expo/vector-icons', "import '@expo/vector-icons'\n"],
  ])('rejects importing %s from core', async (_name, code) => {
    expect(await boundaryRuleIds(code, 'src/sample.ts')).toContain('no-restricted-imports')
  })

  it.each(['window', 'document', 'localStorage', 'sessionStorage', 'indexedDB', 'navigator'])(
    'rejects the browser global %s in core',
    async (name) => {
      const code = `export const value = ${name}\n`
      expect(await boundaryRuleIds(code, 'src/sample.ts')).toContain('no-restricted-globals')
    },
  )

  it('rejects relative imports that leave src from a top-level file', async () => {
    expect(await boundaryRuleIds("import '../tests/helper'\n", 'src/sample.ts')).toContain('no-restricted-imports')
  })

  it('rejects relative imports that leave src from a subfolder', async () => {
    expect(await boundaryRuleIds("import '../../tests/helper'\n", 'src/timer/sample.ts')).toContain(
      'no-restricted-imports',
    )
  })

  it('rejects importing a package from a subfolder', async () => {
    expect(await boundaryRuleIds("import 'react'\n", 'src/timer/sample.ts')).toContain('no-restricted-imports')
  })

  it('rejects bare parent import from a top-level file', async () => {
    expect(await boundaryRuleIds("import '..'\n", 'src/sample.ts')).toContain('no-restricted-imports')
  })

  it('rejects bare grandparent import from a subfolder', async () => {
    expect(await boundaryRuleIds("import '../..'\n", 'src/timer/sample.ts')).toContain('no-restricted-imports')
  })

  it('rejects any file two folders deep', async () => {
    expect(await boundaryRuleIds('export const value = 1\n', 'src/timer/deep/sample.ts')).toContain(
      'no-restricted-syntax',
    )
  })

  it('rejects packages two folders deep', async () => {
    expect(await boundaryRuleIds("import 'react'\n", 'src/timer/deep/sample.ts')).toContain('no-restricted-imports')
  })

  it('allows sibling imports inside src', async () => {
    expect(await boundaryRuleIds("import './types'\n", 'src/sample.ts')).toEqual([])
  })

  it('allows a subfolder to import from the src root', async () => {
    expect(await boundaryRuleIds("import '../types'\n", 'src/timer/sample.ts')).toEqual([])
  })

  it('allows vitest imports in core tests inside src', async () => {
    const code = "import { describe } from 'vitest'\nexport { describe }\n"
    expect(await boundaryRuleIds(code, 'src/sample.test.ts')).toEqual([])
  })

  it('does not apply src rules to files outside src', async () => {
    const code = "import { ESLint } from 'eslint'\nexport { ESLint }\n"
    expect(await boundaryRuleIds(code, 'tests/sample.test.ts')).toEqual([])
  })
})
```

`packages/core/eslint.config.js`:

```js
import js from '@eslint/js'
import tseslint from 'typescript-eslint'
import { defineConfig } from 'eslint/config'

const CORE_MESSAGE =
  '@pomobox/core는 웹과 앱이 공유하는 플랫폼 독립 영역입니다. React·React Native·Expo·브라우저·저장소 구현에 의존하지 마세요.'
const CORE_ESCAPE_MESSAGE = 'src 밖의 모듈을 import하지 마세요. 필요한 기능은 인터페이스로 주입받으세요.'

const corePackagePattern = {
  group: [
    'react',
    'react/*',
    'react-dom',
    'react-dom/*',
    'react-native',
    'react-native/*',
    'expo',
    'expo/*',
    'expo-*',
    '@expo/*',
    'dexie',
    'dexie/*',
    'firebase',
    'firebase/*',
    '@firebase/*',
  ],
  message: CORE_MESSAGE,
}

const coreRestrictedGlobals = [
  'window',
  'document',
  'localStorage',
  'sessionStorage',
  'indexedDB',
  'navigator',
].map((name) => ({ name, message: CORE_MESSAGE }))

function coreBoundary(files, escapeGroup, extraRules = {}) {
  return {
    files,
    rules: {
      'no-restricted-imports': [
        'error',
        { patterns: [corePackagePattern, { group: escapeGroup, message: CORE_ESCAPE_MESSAGE }] },
      ],
      'no-restricted-globals': ['error', ...coreRestrictedGlobals],
      ...extraRules,
    },
  }
}

export default defineConfig([
  {
    files: ['**/*.{ts,tsx}'],
    extends: [js.configs.recommended, tseslint.configs.recommended],
  },
  // src 최상위 파일: src 밖으로 나가는 '../' 금지
  coreBoundary(['src/*.{ts,tsx}'], ['../*', '..']),
  // src 1단계 하위 폴더: src 밖으로 나가는 '../../' 금지
  coreBoundary(['src/*/*.{ts,tsx}'], ['../../*', '../..']),
  // src 2단계 이상: 폴더 깊이 자체를 금지
  coreBoundary(['src/*/*/**/*.{ts,tsx}'], ['../../../*', '../../..'], {
    'no-restricted-syntax': [
      'error',
      { selector: 'Program', message: '@pomobox/core의 src 하위 폴더는 1단계까지만 둡니다(README 참고).' },
    ],
  }),
])
```

import type { ConfigContext, ExpoConfig } from 'expo/config'

import getConfig from '../app.config'

const baseConfig: Partial<ExpoConfig> = {
  name: 'Pomobox',
  slug: 'pomobox',
  scheme: 'pomobox',
  android: { adaptiveIcon: { backgroundColor: '#ffffff' } },
  ios: { supportsTablet: true },
  plugins: ['expo-router'],
}

const originalVariant = process.env.APP_VARIANT

function resolveWith(variant: string | undefined): ExpoConfig {
  if (variant === undefined) {
    delete process.env.APP_VARIANT
  } else {
    process.env.APP_VARIANT = variant
  }
  return getConfig({ config: baseConfig } as ConfigContext)
}

afterEach(() => {
  if (originalVariant === undefined) {
    delete process.env.APP_VARIANT
  } else {
    process.env.APP_VARIANT = originalVariant
  }
})

describe('app.config', () => {
  it('uses dev name and ids when APP_VARIANT=development', () => {
    const config = resolveWith('development')
    expect(config.name).toBe('Pomobox (Dev)')
    expect(config.android?.package).toBe('com.ikjun.pomobox.dev')
    expect(config.ios?.bundleIdentifier).toBe('com.ikjun.pomobox.dev')
  })

  it('uses prod name and ids when APP_VARIANT is unset', () => {
    const config = resolveWith(undefined)
    expect(config.name).toBe('Pomobox')
    expect(config.android?.package).toBe('com.ikjun.pomobox')
    expect(config.ios?.bundleIdentifier).toBe('com.ikjun.pomobox')
  })

  it.each(['production', 'dev', 'Development', ''])('treats APP_VARIANT=%p as production', (variant) => {
    const config = resolveWith(variant)
    expect(config.name).toBe('Pomobox')
    expect(config.android?.package).toBe('com.ikjun.pomobox')
  })

  it('shares slug and scheme across variants', () => {
    expect(resolveWith('development').slug).toBe('pomobox')
    expect(resolveWith(undefined).slug).toBe('pomobox')
    expect(resolveWith('development').scheme).toBe('pomobox')
  })

  it('preserves static android, ios and plugin fields from app.json', () => {
    const config = resolveWith('development')
    expect(config.android?.adaptiveIcon).toEqual({ backgroundColor: '#ffffff' })
    expect(config.ios?.supportsTablet).toBe(true)
    expect(config.plugins).toEqual(['expo-router'])
  })
})

- [ ] **Step 5: ADR-0002 작성**

`docs/decisions/0002-app-first-monorepo.md`:

```markdown
# ADR-0002: 앱 우선 전환과 npm workspaces 모노레포

- 상태: 채택
- 날짜: 2026-11-17
- 관련: ADR-0001(웹 우선 스택)의 순서 결정을 대체한다. 스택 선택(React + Vite 웹, 게스트 로컬 저장 → 로그인 시 서버 이전)은 유지한다.

## 맥락

웹 W0(셋업·배포)을 마친 뒤 W1 설계 도중, 앱을 먼저 개발하기로 했다. 웹은 기능 개발을 보류하되 배포는 유지한다. W1에서 정한 화면·데이터 결정은 앱 A1에 옮겨 쓴다(`docs/superpowers/specs/2026-11-17-w1-web-mvp-notes.md`).

## 결정

1. **순서:** A0(모노레포·앱 셋업) → A1~A3(앱 MVP, 인터랙션, Play 출시) → 로그인·서버 저장 → 웹 W1~W2.
2. **구조:** npm workspaces 모노레포 — `apps/web`, `apps/mobile`, `packages/core`. Turborepo 등 빌드 오케스트레이터는 쓰지 않는다.
3. **core 공유:** `@pomobox/core`는 빌드 없이 TS 소스를 export한다. 경계 규칙(ESLint)과 검증 테스트를 core 패키지가 소유한다.
4. **앱 빌드·배포:** 개발은 로컬 `expo run:android`, 출시는 EAS Build + EAS Submit. Android 먼저. `android/`, `ios/`는 커밋하지 않는다(CNG).
5. **React 버전:** 웹과 앱 모두 Expo SDK가 요구하는 버전(현재 19.3.0)으로 고정한다.

## 선택지 (구조)

- **npm workspaces 모노레포(채택):** 저장소 하나, lock 파일 하나, core를 심볼릭 링크로 공유.
- **앱을 별도 저장소로:** 설정이 단순하지만 core를 복사하거나 패키지로 배포해야 한다.
- **Expo 하나로 웹·앱 통합:** Vite 웹을 버리고 react-native-web으로 옮기는 비용이 들고, 웹 품질이 떨어진다.

## 결과

- 웹과 앱이 같은 core 코드를 쓰고, 경계 규칙이 RN·Expo 의존까지 막는다.
- Vercel은 Root Directory를 `apps/web`으로 바꿔야 한다.
- 로그인이 앱 출시 뒤로 밀려, 그 전까지 앱 데이터는 기기 안에만 있다.
- 호이스팅된 의존성 버전(특히 React)이 어긋나면 런타임 오류가 날 수 있어 버전을 고정한다.
```
